# v18 Outcomes

- [ ] أفضل سلة تحسب السعر الفعلي بعد البونص، وتراجع الحد الأدنى وأيام التوصيل قبل التطبيق.
- [ ] قوالب الطلبات مرتبطة بحساب الصيدلية ولا تختلط بين المستخدمين.
- [ ] جميع حالات الطلبات ظاهرة في فلتر الإدارة مع سجل زمني.
- [ ] الصيدلية تستطيع إرسال اقتراح، ولا تستطيع تعديل الاقتراح بعد الإرسال.
- [ ] الإدارة ترى أحداث الاقتراحات والطلبات وتسجيل الدخول في مركز التشغيل.
- [ ] الإدارة ترى الحسابات النشطة وآخر ظهور للحسابات غير النشطة.
- [ ] عروض الموردين مجمعة؛ يظهر أفضل ثلاثة افتراضياً مع عرض الكل.
- [ ] الإدارة تستطيع إخفاء سعر مورد لصنف أو عدة أصناف أو كل الأصناف.
- [ ] قواعد أيام التوصيل للمناطق محفوظة وتظهر للصيدلية.
- [ ] استيراد الأسعار يدعم الاسم مع التركيز والشكل والشركة من أعمدة منفصلة.
- [ ] v18 مبنية بدون أخطاء TypeScript وتُنشر تحت `/v18/`.
