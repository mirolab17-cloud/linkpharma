# LinkPharma v29

إصدار مستقل مبني على ملفات `v27` عند commit المصدر `a48564bc5866841e1fff125d223cef8e33ac0c2a`؛ تحتفظ هذه النسخة بإصلاحات المصادقة، استيراد الأسعار، pagination، تسجيل الشعار، وإزالة Gemini من المتصفح التي وصلت إلى v27. لا يغيّر مجلد v29 الإصدارات السابقة.

## التغييرات في v29

- إبقاء صفحة التحميل ظاهرة بعد refresh حتى استعادة Firebase Auth/Google redirect وتأكيد ملف المستخدم من Firestore؛ لا تُفتح شاشة الدخول أو المسارات المحمية بسبب مهلة قصيرة أو ملف احتياطي نشط.
- منع callbacks القديمة من جلسة سابقة من استبدال الحساب الحالي، وعرض سبب خطأ الاستعادة مع إجراء إعادة المحاولة.
- إعداد ترتيب عروض المستودعات من مركز تحكم المدير لكل صنف: الأرخص بعد البونص، عشوائي، أحدث تحديثًا، أو أبجديًا.
- تطبيق السياسة على مقارنة الأسعار وتفاصيل الصنف ومقارنة المستودعات المفضلة.
- تقرير التدقيق الساكن لـv27 و50 اقتراحًا في `docs/LinkPharma_v27_Audit_Latest_AR.md`؛ التقرير لقطة مصدرية لـv27 ولا يمثل شهادة أمنية لـv29.
- يعالج v29 إصلاح استعادة الجلسة وسياسة فرز العروض فقط ضمن هذه المهمة؛ لا يدّعي التقرير أو الإصدار إغلاق بقية نتائج v27، ولم تُعدّل قواعد Firebase.

## التشغيل والفحوص

```bash
npm ci --legacy-peer-deps

npm run test:rules:emulator
npm run build
npm run preview -- --host 0.0.0.0
```
