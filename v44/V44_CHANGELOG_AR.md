# Link Pharma v44 — سجل التغييرات

## تم التنفيذ

- إزالة الاعتماد المرئي على الشارع في واجهة بيانات الصيدلية؛ المحافظة والمدينة هما الموقع المعروض، والعنوان التفصيلي يبقى اختيارياً. الحقول القديمة بقيت اختيارية للتوافق مع السجلات السابقة.
- إضافة خريطة تشغيل طلبات للمستودع داخل مساحة المندوب، مع بطاقات مناطق حسب المحافظة/المدينة وفلاتر الحالة والبحث. القراءة مقيدة بـ `supplierId` في التطبيق وقواعد Firestore.
- إضافة زر «عرض كصيدلية» في لوحة المدير. الوضع قراءة فقط، لا يغيّر مستخدم الجلسة، ولا ينفذ طلبات أو يكتب باسم الصيدلية.
- تحويل واجهة أيام التوصيل إلى مربعات اختيار لكل يوم مع إمكانية إضافة/حذف المنطقة، مع حفظ اسم المندوب ووقت التعديل كما في v43.
- إضافة صفحة أصناف المستودع بأسعار المستودع المرتبط فقط، والبحث باسم الدواء أو الشركة، واستخدام رمز صنف مختصر بدلاً من عرض التركيز كعنصر بصري أساسي.
- إضافة سجل دفعات الأسعار وآخر الأسعار المرفوعة للمندوب، مع الرافع، التوقيت، حالة النشر، وعدد المتغير والثابت.
- إضافة إعدادين في مركز القيادة: إجبار دفعات المندوب على مراجعة الإدارة قبل النشر، وتفعيل/إيقاف إشعارات التحديث. عند التفعيل يظهر طلب اعتماد حتى للدفعات الصغيرة، ولا تُكتب الأسعار قبل الاعتماد.
- احتساب `changedCount` و`unchangedCount` من المقارنة الفعلية مع سعر Firebase السابق، مع إشعار موجز يذكر المتغير فقط ولا يعد الثابت كأنه تغيير.
- إضافة سجل بيانات للدفعة يضم حالة المراجعة، الرافع، آخر مراجع، وقت النشر، وآخر تعديل، مع الإبقاء على التحقق الحي عند الطلب وواتساب.
- تحديث قواعد Firestore للسماح للمندوب بقراءة طلبات مستودعه فقط، دون فتح أي طلبات لمستودعات أخرى.
- إضافة v44 إلى GitHub Actions وmanifest النشر.

## التحقق

- `npm run lint` ناجح.
- `npm run build` ناجح.
- `npm run test:rules:emulator` ناجح: 17 حالة.
- `git diff --check` ناجح.

## تنبيه نشر القواعد

نشر GitHub Pages ينشر الواجهة فقط. تفعيل `firestore.rules` في مشروع Firebase الإنتاجي يحتاج صلاحية Firebase CLI مستقلة؛ قواعد v44 موجودة في المستودع ومختبرة على Emulator.


## تحديث لاحق — دخول المدير كصيدلية

- أصبح زر «دخول كصيدلية» يفتح `PharmacyLayout` الحقيقي ومسارات الصيدلية نفسها، وليس شاشة معاينة منفصلة.
- يحفظ النظام جلسة المدير الأصلية في الذاكرة ويعرض ملف الصيدلية المحدد كهوية واجهة مؤقتة.
- يتم تجاوز الاشتراك والفترة التجريبية داخل وضع المعاينة للمدير فقط، دون تعديل اشتراك الصيدلية في Firebase.
- يظهر شريط ثابت يوضح أن الوضع معاينة مدير، مع زر «العودة إلى الإدارة» لاستعادة جلسة المدير والمسار الإداري.
- لا يتم تغيير جلسة Firebase أو تسجيل الخروج منها عند التبديل.

## تحقق التحديث
