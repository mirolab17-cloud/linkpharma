- [x] تعديل مسار PWA إلى `/v24/` وإضافة v24 إلى Workflow نشر GitHub Pages دون تغيير ملفات الإصدارات القديمة.
- [x] نجاح `npm run lint` و`npm run build` محليًا على ARM64 بعد تثبيت الحزم الثنائية الاختيارية المفقودة في بيئة الاختبار.

## ملاحظات نشر وتشغيل مهمة
- النشر عبر الموقع يتم بعد دفع التغييرات وتشغيل GitHub Actions بنجاح.
- **قواعد Firestore غير منشورة تلقائيًا**: المستودع لا يحتوي `firebase.json` أو `.firebaserc`. قبل تفعيل القوالب السحابية وتعديل الطلبات، راجع وادمج `firestore.rules` المرفق مع القواعد المعتمدة في مشروع Firebase ثم انشرها من بيئة Firebase CLI موثوقة. لم تُجر أي كتابة اختبارية إلى قاعدة الإنتاج.
- استيراد الصيدليات يحدّث ملفات مستخدمين قائمة لها UID صالح؛ لا يستحدث حسابات Firebase Authentication أو يرسل دعوات تسجيل.
- الاستعادة تدمج السجلات حسب المعرف ولا تحذف بيانات؛ قد تستبدل سجلًا موجودًا له المعرف نفسه، لذلك يلزم مراجعة المعاينة ووجود نسخة احتياطية مسبقة.

## غير منفذ بالكامل
- لم يتم توحيد شاشات الإدارة ومركز القيادة في شاشة واحدة؛ بقيت الميزات موزعة على الشاشات الموجودة.
- لم يُبنَ نموذج مطابقة مستقل للعبوة/قواعد وحدات الجرعة؛ أعمدة العبوة تضاف إلى نص الاسم للمراجعة والمطابقة التقريبية، وتظل الحالات الملتبسة بحاجة لمراجعة المستخدم.
- أيام التوصيل حسب المنطقة موجودة؛ لم تُضف بعد أداة جدولة/حساب تاريخ تسليم نهائي موحد في السلة.
- لم يُجر اختبار تكاملي حي مع Firebase Authentication/Firestore أو اختبار قبول داخل متصفح مستخدم. لم يُنشر الإصدار بعد حتى يتم دفع التغييرات ومراجعة تشغيل GitHub Actions.
