# Link Pharma v39

## ما تم تنفيذه

- إضافة صفحة إدارية جديدة: **الباقات وتجربة الاشتراك**.
- تخصيص مستقل لحالات انتهاء التجربة، انتهاء الاشتراك، الحساب الموقوف، والحساب قيد المراجعة.
- تعديل العنوان والوصف والشارة وزر الإجراء وقالب واتساب من لوحة الإدارة.
- إدارة الباقات: الاسم، السعر، الفترة، الشارة، نسبة التوفير، المزايا، الإظهار/الإخفاء، الإضافة والحذف.
- معاينة هاتفية مباشرة داخل لوحة الإدارة مع تصميم mobile-first.
- ربط شاشة الصيدلية الديناميكية بالسياسات المحفوظة، مع التحكم في إظهار الباقات وإحصائيات القيمة.
- الحفاظ على مشاهد 3D المتحركة الحالية ومربعات المستودع والصيدلية في التصميم الأساسي.
- إضافة مسار `/admin/subscription-policies` إلى manifest وسير نشر GitHub Pages.

## التحقق

- `npm run lint` ناجح.
- `npm run build` ناجح.


## تحديث الخصومات

أضيفت حقول منفصلة للسعر الحالي بعد الخصم، والسعر قبل الخصم، ونص التوفير. عند إدخال مثال مثل `100 ₪` كسعر حالي و`120 ₪` كسعر سابق، يظهر السعر الحالي بلون Link Pharma ويظهر السعر السابق مشطوباً، مع شارة مثل `وفر 17%` في المعاينة الهاتفية وشاشة الصيدلية.
