# LinkPharma V51 — إصلاح مطابقة الأصناف التجارية وحفظ الأسماء البديلة

## الأساس
- إصدار مستقل مبني على مصدر V48؛ لا يغيّر ملفات V48 ولا يغيّر قاعدة البيانات أو قواعد الصلاحيات.

## الإصلاح
- تعديل مسار حفظ الاسم البديل حتى لا يستدعي تحميل قائمة الأسماء البديلة كاملة عبر `getProductAliases()` أثناء عملية الحفظ.
- فحص المستند المستهدف مباشرة باستخدام المعرّف الحتمي للاسم البديل، ثم التحقق من عدم ارتباطه بصنف آخر قبل الكتابة.
- تحديث الذاكرة المؤقتة المحلية بعد الحفظ مع الاحتفاظ بحماية تعارض الاسم البديل.

## التحقق
- يمرّ الإصدار بفحوص TypeScript واختبارات استيراد الكتالوج وقواعد Firestore ضمن سير نشر GitHub Actions.
- يجب تأكيد نجاح حفظ الاسم البديل واستمراره بعد إعادة تحميل الصفحة على بيانات البيئة الفعلية؛ لم تُجرَ كتابة تجريبية على قاعدة بيانات الإنتاج.
