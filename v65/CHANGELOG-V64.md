# v64 — تحسين سرعة عرض الكتالوج

تستخدم صفحة أسعار الصيدلية لقطات الأسعار المجمعة والمحدّثة حسب المورد أولاً، بدلاً من قراءة جميع وثائق الأسعار الحية في الحالة المعتادة. إذا لم توجد لقطة أو تعذر تحميل قطعة منها، تعود الصفحة لقراءة الأسعار الحية حتى لا تعرض نتيجة ناقصة بصمت. كما أضيف cache ذاكرة لمدة خمس دقائق لقطات المنتجات والأسعار لتقليل إعادة تحليل JSON وإعادة تنزيل اللقطات عند التنقل، مع ربط الإبطال بتحديث المنتجات والأسعار.

عند وصول تحديثات قوائم المنتجات والمواد الفعالة والموردين، تُجمع عمليات حفظ النسخة المحلية وتُؤجل إلى وقت خمول المتصفح بدلاً من تحويل المجموعة كاملة إلى JSON داخل callback الخاص بـ Firestore. يساعد ذلك على تخفيف تجمّد واجهة الصفحة عند وصول دفعة كبيرة من التحديثات، مع بقاء الكتابة المحلية مؤجلة لفترة قصيرة.

كتالوج المندوب يرسم 50 بطاقة أولاً ويتيح عرض المزيد على دفعات 50، بينما يظل البحث والتصدير شاملين لكل النتائج المطابقة. أضيفت كذلك خطوات فحص وبناء v64 إلى GitHub Actions، بما فيها اختبارات قراءة Excel والمطابقة الحالية.

إذا غابت لقطات الأسعار أو كانت متأخرة، قد يلزم جلب الأسعار الحية؛ لذا يظل التحميل متأثراً بحجم البيانات والاتصال. لم تتغير صلاحيات Firestore أو بنية البيانات. هذه النسخة لم تُرفع أو تُنشر بعد.
