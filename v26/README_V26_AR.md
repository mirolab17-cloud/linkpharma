# LinkPharma v26

هذه نسخة كاملة من ملفات `v25` مع إضافة واجهة الموقع العامة من حزمة `LinkPharma_v28_public_site.zip`.

## ما الذي تغير؟
- الصفحة الرئيسية العامة هي `index.html`، والصفحات العامة الأخرى (عن المنصة، المميزات، كيف تعمل، الأسئلة الشائعة، التواصل، الخصوصية، الشروط، و404) تُنشر من `public/` إلى جذر الموقع.
- ملفات التصميم والتفاعلات العامة هي `public/styles.css` و`public/app.js`.
- تطبيق المنصة الأصلي محفوظ في `platform.html` مع كل مكونات React والمصادقة وملفات v25.
- أزرار «تسجيل الدخول» في صفحات الموقع تفتح `platform.html#/login`، وهو مسار تسجيل الدخول الفعلي في تطبيق `HashRouter`.
- يجمع Vite الموقع العام وتطبيق المنصة في بناء واحد متعدد الصفحات.

## التشغيل والبناء
من داخل هذا المجلد: `npm install` ثم `npm run dev` للمعاينة أو `npm run build` للبناء. أعد ضبط متغيرات Firebase حسب ملف `.env.example` ومتطلبات النشر المعتادة.

نموذج التواصل في الحزمة يتحقق محليًا فقط ولا يرسل الرسائل إلى خادم. كما أن نصوص الخصوصية والشروط مذكورة في الحزمة كمسودات تحتاج مراجعة واعتمادًا قبل النشر الرسمي.
