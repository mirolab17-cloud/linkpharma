# LinkPharma — الواجهة العامة

حزمة واجهة أمامية متعددة الصفحات باستخدام HTML وCSS وJavaScript عادي (Vanilla JS)، واتجاه عربي RTL.

## الصفحات
- `index.html` الصفحة الرئيسية
- `about.html` عن المنصة
- `features.html` المميزات
- `how-it-works.html` كيف تعمل؟
- `faq.html` الأسئلة الشائعة
- `contact.html` تواصل معنا
- `privacy.html` سياسة الخصوصية (مسودة تحتاج مراجعة واعتمادًا)
- `terms.html` الشروط والأحكام (مسودة تحتاج مراجعة واعتمادًا)
- `404.html` صفحة غير موجودة
- `styles.css` التصميم المتجاوب
- `app.js` تفاعلات قائمة الهاتف والأسئلة الشائعة والتحقق من النموذج

## المعاينة
افتح `index.html` في متصفح حديث. الخط العربي يُحمّل من Google Fonts عند توفر الإنترنت.

## الدمج داخل v28
1. فك ضغط ZIP.
2. انسخ الملفات إلى مجلد مستقل داخل v28 مثل `public-site/` أولًا.
3. إذا كان v28 يستخدم React أو Vue أو Next أو نظام توجيه خاصًا، لا تستبدل إعداداته؛ انقل التصميم والمحتوى إلى مكونات المشروع بدلًا من استبدال الملفات.
4. زر تسجيل الدخول حاليًا تنبيه تجريبي، ويجب ربطه بمسار الدخول الفعلي في v28.
5. نموذج التواصل يتحقق من المدخلات محليًا فقط، ولا يرسل بيانات إلى خادم. اربطه بخدمة خلفية موثوقة قبل الاستخدام.
6. نصوص الخصوصية والشروط مسودات أولية تحتاج مراجعة قانونية.
7. لا تحتوي الحزمة على بيانات منتجات أو أسعار أو أسماء مستودعات حقيقية أو معلومات اتصال مخترعة.

الحزمة مستقلة ولا تتضمن ملفات v25 أو v28 ولا تعدّلها.
