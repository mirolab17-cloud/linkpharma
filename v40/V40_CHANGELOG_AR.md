# Link Pharma v40

## الإصلاحات

- إصلاح سباق تسجيل الدخول: ينتظر التطبيق تثبيت صلاحية المدير من Firebase قبل توجيه الحساب، فلا يظهر حساب المدير كصيدلية أو يعود إلى شاشة الدخول بسبب الدور المؤقت.
- إزالة الشارع من واجهة بيانات الصيدلية والفروع وقاموس المواقع وجدول التوصيل؛ أصبح الاختيار محافظة ومدينة فقط.
- جعل العنوان التفصيلي اختيارياً، مع استمرار قبول البيانات القديمة التي تحتوي على شارع دون عرضها أو طلبها.
- حفظ سياسات الباقات في Firebase `settings/public` بالإضافة إلى التخزين المحلي؛ حذف الباقة أو تعديلها يبقى محفوظاً بعد تحديث الصفحة ومن جهاز آخر.
- إضافة تحميل السياسة السحابية في شاشة الصيدلية قبل عرض الباقات.

## التحقق

- `npm run lint` ناجح.
- `npm run build` ناجح.
