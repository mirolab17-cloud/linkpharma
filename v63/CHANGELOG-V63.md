# V63
- اعتماد الأسعار: كتابة الدفعات بالتوازي (12 دفعة معاً) بدل التتابع.
- قراءة أسعار المورد باستعلام واحد.
- إعادة بناء Snapshot المورد والإشعارات تعمل بالخلفية بدل انتظارها.
- الواجهة لا تنتظر إعادة تحميل البيانات بعد الاعتماد.
- قراءة خلايا ورقة Excel الفعلية واكتشاف الصفوف خارج نطاق !ref المبتور؛ إضافة اختبار يكشف الصف 800 حتى إن أعلن الملف أن الورقة أقصر.
- إضافة تشخيص قبل المطابقة وبعدها يعرض صفوف الورقة وغير الفارغة والصحيحة والمستبعدة، إضافة إلى حجم كتالوج الأصناف والأسماء البديلة المحملة.
- دعم صيغ البونص 10+1 و10*1 و10x1 و10×1 والأرقام العربية، مع اعتبار العدد الأول المدفوع والثاني بونص.
- توسيع التصدير في صفحة الإدارة والمندوب إلى اختيار أعمدة Excel/JSON/PDF؛ وتضمين أسعار الموردين عند تصدير الإدارة، وسعر المستودع عند تصدير المندوب.
- تحويل اختيار صنف العرض لدى الإدارة والمندوب إلى بحث واختيار من كتالوج الأصناف، مع حفظ productId والتحقق من وجوده في قواعد Firestore للمندوب.
