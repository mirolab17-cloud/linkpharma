# LinkPharma v55 — تتبع الاستخدام والتصدير وتحسينات الهاتف

## الأساس
- نسخة مستقلة مبنية على v54، مع الحفاظ على مجلدات الإصدارات السابقة.
- تشمل تحسينات v54 في استيراد الأسعار، المطابقة، معالجة الدفعات الكبيرة، والسلة الذكية التي تتيح مراجعة البدائل يدوياً قبل تطبيقها.

## نشاط الحساب والجهاز
- إنشاء معرّف عشوائي مجهول محفوظ على الجهاز عبر `localStorage`؛ لا يجمع بصمة المتصفح أو خصائص الجهاز.
- تسجيل عدد مرات الدخول، آخر دخول، آخر نشاط، ومعرّفات الأجهزة التي سجلت الدخول.
- تحديث حضور محدود عند ظهور التطبيق ودورية كل خمس دقائق، مع منع إعادة الكتابة من حلقة مستمع Firestore.
- شاشة «نشاط المستخدمين والأجهزة» في لوحة الإدارة تعرض سجل الدخول والأجهزة المعروفة.
- تُعرض البيانات كمؤشرات نشاط وليست سجلاً أمنياً موثوقاً أو تأكيداً لوجود جلسة نشطة؛ Firebase من واجهة العميل لا يتيح هنا إنهاء جلسات الأجهزة الأخرى عن بعد.
- أضيف للمستخدم خيار مؤكد لمسح الكاش وبيانات الجلسة المحلية لهذا المتصفح فقط، دون حذف الحساب أو البيانات السحابية.

## تصدير القوائم الإدارية
- مكوّن مشترك يدعم Excel وJSON، وفتح نسخة طباعة عربية RTL يمكن حفظها بصيغة PDF.
- أضيف إلى قوائم الصيدليات، الأصناف، الطلبات، والمستودعات؛ يصدر المجموعة المفلترة المعروضة في الصفحة.
- يتضمن التصدير هوية LinkPharma وتاريخ التصدير، مع تعقيم نص HTML في معاينة الطباعة.

## تجربة الهاتف والملف الشخصي
- ضبط تباعد ومقاسات الشريط العلوي وزر تثبيت التطبيق على الشاشات الصغيرة لتقليل تداخل الزر مع الشعار.
- إضافة دعوة عربية لتفعيل إذن إشعارات المتصفح في الملف الشخصي، مع حالات الإذن المدعوم/المفعّل/المرفوض. لا يعاد طلب الإذن بعد رفضه.
- إضافة شعار المنصة في شاشة الخطط/تجديد الاشتراك.
- إظهار الأيام المتبقية حتى انتهاء الاشتراك باستخدام تاريخ الانتهاء الفعلي الموجود في الحساب، المرتبط بسياسات الإدارة؛ لا تنشئ هذه الشاشة مدة تجريبية جديدة.

## الخصوصية والحدود
- عدادات الاستخدام ووقت النشاط ومعرّف الجهاز مقدمة لأغراض متابعة إدارية، وليست وسيلة مصادقة أو إثبات هوية؛ بيانات الطرف العميل قابلة للتلاعب.
- دعوة الإشعارات تطلب إذن المتصفح فقط. وصول الإشعارات فعلياً يحتاج تكاملاً خادمياً (مثل خدمة Push) وإعداد مفاتيح واشتراك، وليس جزءاً من هذا التغيير.
- زر مسح البيانات محلي ولا يسجل خروج الأجهزة الأخرى ولا يمسح بيانات Firebase السحابية.

## التحقق
- `npm run lint` — ناجح.
- `npm run test:catalog-import` — ناجح.
- `npm run test:product-matching` — ناجح.
- `npm run test:rules:emulator` — 17 اختباراً ناجحاً قبل إضافة حالات الحضور؛ يعاد تشغيلها بعد إضافة الحالات الجديدة.
- `npm run build` — ناجح.
- البناء المحلي على ARM استلزم تثبيتاً مؤقتاً لحزم TypeScript وLightning CSS المتوافقة دون تعديل `package.json` أو ملفات القفل.
