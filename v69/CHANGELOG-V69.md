# LinkPharma v69 — مراجعة القاموس العام

- اقتراح أصناف مشابهة للاسم البديل بدرجات تشابه وتحذير عند اختلاف التركيز أو الشكل؛ الاقتراحات لا تغيّر البيانات تلقائياً.
- كشف الأسماء المتطابقة بعد التطبيع والأسماء المتقاربة للمراجعة.
- اختيار حتى 400 اسم ونقل ربطها دفعة واحدة إلى صنف موجود مع معاينة وتأكّد صريح.
- تعديل قواعد Firestore ليستطيع المدير نقل الربط مباشرة، مع منع الأدوار الأخرى وفحص وجود الصنف.
- تحليل القاموس على دفعات لتفادي تجميد واجهة الإدارة، مع اختبارات للاقتراحات والتكرار وصلاحيات قاعدة البيانات.
