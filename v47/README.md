# LinkPharma v47

نسخة مبنية على v46 مع الحفاظ على النسخة الأصلية. تتضمن v47 قائمة إدارة مرتبة بأقسام، صفحة ظهور الأصناف، وصلاحيات الصيدليات (رفع أسعار، إنشاء أصناف ومواد فعالة).

## أبرز التغييرات

- لا تسجّل المنصة تغييرات الصفحة أو أحداث النشاط الروتينية، ولا تكتب أو تحدّث حضور المستخدمين عند فتح كل صفحة.
- سجل الإدارة يعرض أنواع التغييرات المهمة فقط، ويحد قراءة سجل النشاط وتاريخ الأسعار إلى أحدث 50 عن فتح الصفحة.
- لوحة الإدارة لا تجلب مجموعات المستخدمين والطلبات والمنتجات والاستيرادات تلقائياً؛ المؤشرات الكبيرة تُحمّل بزر صريح، مع استبعاد الأسعار وسجل النشاط منها.
- مركز القيادة لا يقرأ شيئاً عند فتحه؛ أقسام الصيدليات أو الأصناف أو الموردين أو الإعدادات تُحمّل فقط عند اختيارها. الأسعار لا تُحمّل مع الكتالوج، والنسخ الكامل لا يبدأ إلا بزر التنزيل.
- أزيلت واجهة الحملات الجماعية، مع الإبقاء على الإشعار الفردي الموجّه لحساب عند الحاجة.
- حقل `packSize` اختياري في نموذج الصنف واستيراد Excel/CSV، ويظهر في قائمة المقارنة؛ أمثلة: `20 قرصاً` أو `5 أمبولات` أو `10 تحاميل`.
- أثناء ربط صف سعر غير معروف، يمكن تحديد نوعه دواءً أو مستلزماً طبياً أو غير دوائي؛ المادة الفعالة قابلة للبحث في القائمة المخزنة، وتركها دون اختيار يحفظ الصنف كغير دوائي.
- إضافة الأصناف غير المربوطة تحفظها في دفعات قصيرة وتعرض تقدماً وعدّادات المطابقة أثناء التنفيذ؛ عند فشل الحفظ تظهر الصفوف المتبقية لإعادة المحاولة بدلاً من إعلان نجاح غير مؤكد.
- صفحة الملف الشخصي تعرض اسم الصيدلية والمالك، مع صفحات مستقلة لتحرير الملف وطلب ربط المندوب بمستودع.
- إعداد رقم دعم مدير المنصة وإعداد ترتيب عروض المستودعات (الأرخص، أحدث تحديث، أو ترتيب عشوائي ثابت خلال اليوم) متاحان في لوحة الإدارة.
- تحميل خط Cairo وتوحيد اتجاه RTL ومظهر الواجهات العربية.

## مزامنة الأسعار والمواقع

- المنتجات والمواد الفعالة والمستودعات تُحمّل عبر listeners مشتركة؛ بعد snapshot البداية تُطبّق الإضافات والتعديلات والحذف عبر `docChanges()` بدلاً من تكرار `getDocs()` الكامل أثناء بقاء الجلسة متصلة. يستفيد المتصفح من cache Firestore الدائم إذا كان مفعلاً على الجهاز. أول تحميل لجهاز جديد أو مسح بيانات المتصفح أو إعادة اتصال تُعامل كقراءة فعلية؛ لا يوجد ضمان أن كل فتح للتطبيق مجاني.
- أسعار المورد تُجلب للأصناف الظاهرة فقط، وبنطاق المستودعات التي يسمح بها حساب المستخدم. ذاكرة الأسعار مفصولة حسب الحساب والصلاحية وقائمة الأصناف، وتُستخدم لمدة خمس دقائق.
- يمكن تعديل صف Excel قبل المطابقة، والبحث عن صنف المنصة أو تعديل بياناته مع بقاء معرف الصنف، وربط اسم مورد بديل خاص بالمستودع. الربط الآلي لا يعتمد التشابه الغامض أو هوية متعارضة.
- محرر الإدارة يدير المحافظات والمدن والمناطق الفرعية، مع أزرار حذف وتنظيف تلقائي للبنود الفارغة. تظهر المنطقة للصيدلية أو المندوب فقط إذا كانت معرفة للمدينة، وهي اختيارية.
- ملف `firestore.rules` يتضمن صلاحيات الفروع والأسماء البديلة، والتحقق من مرجع الصنف عند كتابة السعر، وحالة تقدم استيراد المندوب وقفل التراجع. نشر GitHub Pages لا ينشر قواعد Firebase تلقائياً؛ يجب نشر هذه القواعد إلى مشروع Firebase المرتبط قبل استخدام الاستيراد والفروع والأسماء البديلة على الإنتاج.
- تراجع الأسعار يعيد الكتابات في Firestore عبر معاملات مع lease مؤقت، ويستعيد الدفعات الجزئية بعد الانقطاع دون استبدال سعر أحدث؛ تبقى علامة `rolled_back` لمنع أي chunk متأخر من إعادة إنشاء الدفعة.

## التحقق محلياً

```bash
npm install
npm run lint
npm run build
npm run test:rules:emulator
```

يمكن فتح النسخة المنشورة على المسار `/v47/` ضمن موقع GitHub Pages للمستودع بعد نشرها.
