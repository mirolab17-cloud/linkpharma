# 💊 منصة مقارنة أسعار الأدوية للصيدليات والمستودعات

منصة ويب متكاملة مبنية باستخدام **React 18 + Vite + Tailwind CSS + Firebase v10** مخصصة للصيدليات ومستودعات الأدوية لمقارنة أسعار الأدوية بين الموردين وإرسال الطلبيات المجمعة عبر تطبيق واتساب بنقرة واحدة، بالإضافة لإمكانية استيراد وتحديث قوائم أسعار الموردين بملفات Excel/CSV أو الصور والنصوص عبر **Gemini AI** والمطابقة الذكية التقريبية عبر **Fuse.js**.

---

## 🚀 المميزات الرئيسية

1. **واجهة عربية RTL كاملة ومتجاوبة**:
   - خط **Cairo** المريح للعين.
   - لون أساسي أخضر طبي أنيق (`#0f9d7a`).
   - متجاوبة بالكامل للهواتف الذكية مع شريط سفلي خاص بالصيدلية وقائمة جانبية قابلة للطي للأدمن.
   - الجداول تتحول تلقائياً لبطاقات على شاشات الجوال.

2. **أدوار المستخدمين والأمان الصارم**:
   - **مدير النظام (Admin)**: تحكم كامل بالمواد الفعالة، الأصناف التجارية، المستودعات، الصيدليات، رفع وتحديث الأسعار، وسجل الطلبيات.
   - **الصيدلية (Pharmacy)**: مقارنة الأسعار بين الموردين المسموحين، تمييز الأرخص، شارة التنبيه للأسعار الأقدم من 7 أيام، سلة مشتريات مجمعة لكل مورد، وإرسال فوري إلى واتساب.
   - التسجيل الجديد يبدأ بحالة **معلقة (Pending)** بانتظار تفعيل الأدمن، مع إلزامية إكمال الملف الشخصي قبل التصفح.

3. **محرك رفع أسعار الموردين الذكي (Import Engine)**:
   - مسار **Excel / CSV**: قراءة أوراق العمل المتعددة، تحديد صف البداية، معاينة أول 20 صفاً، ربط الأعمدة، وحفظ قالب الترتيب للمورد.
   - مسار **الذكاء الاصطناعي (Gemini Vision & Text)**: استخراج الأسماء والأسعار من صور الفواتير أو النصوص الملصوقة وجدولتها في محرر قابل للتعديل.
   - محرك مطابقة ثنائي المرحلة: تطابق تام بعد التطبيع العربي، وتطابق تقريبي عبر **Fuse.js** مع اقتراح أقرب 3 أصناف وإمكانية إنشاء صنف جديد فورياً.
   - حفظ التغييرات في سجل التاريخ `priceHistory` مع إمكانية **التراجع عن دفعة الاستيراد (Rollback)** واستعادة الأسعار السابقة فوراً.

4. **بيانات تجريبية جاهزة (Seed Data)**:
   - يتضمن التطبيق أزراراً في لوحة التحكم لإدخال بيانات تجريبية فورية تشمل 10 مواد فعالة، 30 صنفاً تجارياً، 3 مستودعات بأسعار مختلفة، وطلبيات سابقة، مع زر للمسح السريع.

## 🌐 دليل إعداد Firebase خطوة بخطوة

### الخطوة 1: إنشاء مشروع Firebase
1. توجه إلى [Firebase Console](https://console.firebase.google.com).
2. انقر على **"Add project"** وقم بتسمية المشروع ثم اضغط **Continue**.
3. قم بتعطيل أو تفعيل Google Analytics حسب رغبتك، ثم انقر **"Create project"**.

### الخطوة 2: تفعيل خدمة المصادقة (Authentication)
1. من القائمة الجانبية في Firebase Console، اختر **Build -> Authentication**.
2. انقر على **"Get started"**.
3. في تبويب **Sign-in method**:
   - فعّل **Email/Password** (البريد الإلكتروني وكلمة المرور).
   - فعّل مزود **Google**، وحدد البريد الإلكتروني لدعم المشروع.
4. في تبويب **Settings -> Authorized domains**:
   - تأكد من إضافة النطاق الخاص بتطبيقك (مثلاً نطاق المعاينة أو نطاق الاستضافة الخاص بك).

### الخطوة 3: تفعيل قاعدة بيانات Firestore
1. من القائمة الجانبية، اختر **Build -> Firestore Database**.
2. انقر على **"Create database"**.
3. اختر موقع الاستضافة الأقرب لمنطقتك (مثل `europe-west1` أو `us-central1`).
4. اختر وضع البداية (Start in test mode أو production mode).

### الخطوة 4: نسخ إعدادات Firebase إلى المشروع
1. في Firebase Console، انقر على أيقونة **Project Settings** (علامة الترس) في أعلى القائمة الجانبية.
2. تحت قسم **"Your apps"**، انقر على أيقونة الويب `</>`.
3. اكتب اسماً للتطبيق ثم اضغط **Register app**.
4. انسخ كائن `firebaseConfig` والصقه إما في ملف `.env` أو مباشرة داخل ملف `src/firebase.js`:
```javascript
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "your-app.firebaseapp.com",
  projectId: "your-app-id",
  storageBucket: "your-app.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

### الخطوة 5: إضافة مفتاح Gemini API
لتمكين الذكاء الاصطناعي من استخراج الأسعار من الصور والنصوص:
1. احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/).
2. أضفه في ملف `.env`:
```env
VITE_GEMINI_KEY="AIzaSyYourGeminiApiKeyHere"
```

## 👑 تعيين أول أدمن (Admin Promotion)

نظام الصلاحيات يعتمد على حقل `role` داخل مستند المستخدم في مجموعة `users`. لتعيين أول حساب كمدير للنظام:
1. افتح التطبيق وسجّل حساباً جديداً بالبريد وكلمة المرور في صفحة `/register`.
2. افتح **Firebase Console -> Firestore Database**.
3. افتح مجموعة `users`، وابحث عن المستند الذي يطابق معرف المستخدم (UID) الخاص بك.
4. عدّل الحقول التالية:
   - غيّر حقل `role` من `"pharmacy"` إلى `"admin"`.
   - غيّر حقل `status` من `"pending"` إلى `"active"`.
5. قم بتحديث صفحة التطبيق في المتصفح، وسيتم توجيهك تلقائياً إلى لوحة الأدمن `/admin` بكامل الصلاحيات.

## 🔒 نشر قواعد الأمان (Firestore Rules) والفهارس

الملفات جاهزة في جذر المشروع (`firestore.rules` و `firestore.indexes.json`):

1. قم بتثبيت أدوات Firebase CLI إن لم تكن مثبتة:
```bash
npm install -g firebase-tools
```
2. سجّل الدخول:
```bash
firebase login
```
3. اربط المشروع:
```bash
firebase use your-project-id
```
4. انشر القواعد والفهارس المركبة:
```bash
firebase deploy --only firestore:rules,firestore:indexes
```

## 🚀 النشر على Firebase Hosting

1. بناء المشروع للإنتاج:
```bash
npm run build
```
2. تهيئة ونشر الاستضافة:
```bash
firebase init hosting
# عند السؤال عن Public directory اكتب: dist
# عند السؤال عن Single-page app اختر: Yes (y)
firebase deploy --only hosting
```
ستحصل فوراً على رابط التطبيق المنشور على الإنترنت.
