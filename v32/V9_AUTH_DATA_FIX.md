# فارما لينك v9

تعالج هذه النسخة فقدان بيانات المستخدم عند إعادة التحميل أو تسجيل الدخول مرة أخرى:

- Firebase Auth يستخدم IndexedDB وlocal persistence.
- لا يتم توجيه Google إلى مسار محمي قبل اكتمال ملف المستخدم.
- المدير يُكتشف عبر `admins/{uid}` مع السماح بقراءة علامته فقط.
- طلبات المستخدم تُقرأ باستعلام `pharmacyId == uid`، فلا تُرفض القواعد ولا تظهر السلة/الطلبات فارغة بسبب فشل قراءة جماعية.
- يتم الحفاظ على `profileComplete` والملف القديم وعدم إنشاء ملف جديد لمستخدم Firebase موجود.
- حقول المالك والموقع والعنوان مسموحة في تحديث ملف المستخدم.

يجب نشر ملف `firestore.rules` على قاعدة Firestore الفعلية ذات Database ID المستخدم في إعداد Firebase.
