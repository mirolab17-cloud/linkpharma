# LinkPharma V35

نسخة مستقلة من `v32` مع تحسينات موجهة لتقليل القراءات المتكررة، وإدارة عروض المستودعات، وصلاحيات مندوب قابلة للفصل.

## تشغيل محلي

```bash
npm install
npm run dev
```

## فحوصات الإصدار

```bash
npm run lint
npm run test:rules:emulator
npm run build
```

## المميزات الخاصة بـ V35

- كاش ذاكرة لخمس دقائق لصفحات أسعار المنتجات ودفعات الكتالوج، مع تمييز بيانات الأسعار بحسب المستخدم والدور ونطاق المستودع.
- قراءة أحدث 100–200 حدث في لوحات الملخص، مع الإبقاء على سجل التدقيق الكامل.
- صفحة مستقلة لإضافة العروض وتعديلها وجدولتها زمنيًا أو إيقافها، للإدارة والمندوب المخول.
- عزل المندوب بقواعد Firestore إلى مستودعه، وتفويض صفحة العروض منفصلة عن صلاحية رفع الأسعار.

راجع [تفاصيل الميزات واستهلاك Firebase و20 اقتراحًا للمرحلة التالية](./V35_FEATURES_AND_FIREBASE_AR.md) و[ملاحظات النشر](./DEPLOYMENT_V35_AR.md).

> GitHub Pages ينشر ملفات الموقع فقط. قواعد Firestore في `firestore.rules` تحتاج مراجعة ودمجًا منفصلًا مع إعدادات Firebase الإنتاجية قبل تشغيل صفحة العروض على قاعدة الإنتاج.
