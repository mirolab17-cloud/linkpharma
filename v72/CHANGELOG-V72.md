# LinkPharma v72 — إصلاح عمود "السابق" في مراجعة الأسعار

- المشكلة: أسعار المورد الحالية كانت تُحمَّل مرة واحدة عند اختيار المورد ولا تُحدَّث بعد الاعتماد، فتظهر الدفعة الثانية للملف نفسه مقارنةً ببيانات قديمة ("صنف جديد" وفروقات خاطئة).
- الحل: تحديث الأسعار الحالية (مع مسح الكاش) بعد كل اعتماد وعند دخول خطوة المراجعة.
