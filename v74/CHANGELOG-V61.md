# LinkPharma V61 — Change log

## Included in this revision
- Fixed the mobile navigation install control so it displays as a compact icon on narrow screens and shows the full “تثبيت التطبيق” label on larger screens.
- Updated the package metadata to `linkpharma-v61`, version `61.0.0`.

## Not yet implemented or verified
The following items from the V61 request still require implementation and testing before this can be called a complete release:
- Device fingerprint/identifier and sign-in/activity history.
- Reliable offline persistence and conflict-safe synchronization.
- Admin-configurable trial duration and scoped/expiring permissions.
- Filtered Excel, JSON, and PDF exports with optional branding.
- Profile notification opt-in call-to-action and logo placement in plans/previews.
- Smart-cart lower-price alternatives with an admin visibility switch.
- End-to-end build, security-rules, and mobile-browser testing.

The previous V60 source remains unchanged on `main`; this work is isolated on branch `v61`.
