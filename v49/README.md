# LinkPharma V49 — Login experience

Responsive Arabic RTL login page with a medical-white and emerald palette, CSS 3D motion, and mobile-first layout.

**Important scope note:** this is a standalone redesigned login entry page, not a full copy of the V48 application source tree. It signs in with the existing Firebase project, then hands off to `../v48/platform.html#/login` so the current application remains responsible for loading profiles, roles, permissions, and app routes.

Preview: https://mirolab17-cloud.github.io/linkpharma/v49/
